# Prem's 100-Day Track

A calm morning routine and a 100-day study track for an AI Consultant role.

- **Today**: breathing, a Psycho-Cybernetics visualisation, a sticky-note self-image, and a success log.
- **Learn**: 100 daily lessons in 6 phases, each with a note, a diagram, an animated visual lesson and narration.
- **Plan**, **Mock** and **Projects**: progress grid, mock interviews and 6 portfolio projects.

## How it works

- One static page. No server, no build step.
- Progress is saved in the browser (localStorage). Use **Settings → Save backup file** to keep a copy.
- The tutor, answer grading and mock interviews use the Gemini API. You paste your own key in **Settings**. The key stays in your browser and is never part of this repository.

## Update the site

Edit `index.html`, commit and push to `main`. GitHub Pages republishes in about a minute.
